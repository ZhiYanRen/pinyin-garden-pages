# 拼音小花园

正式网站：https://zhiyanren.github.io/pinyin-garden-pages/

私有源码：https://github.com/ZhiYanRen/pinyin-garden

公开发布文件：https://github.com/ZhiYanRen/pinyin-garden-pages


为已会拼读、但听写容易混淆的孩子制作的网页学习应用，打开网址即可使用。

## 开始使用

打开正式网址即可练习，无需登录。需要离线练习时，进入「家长设置」→「下载离线声音包」，等待完成后即可断网使用。

## 已包含

- 26 个拼音专项，224 道原创练习：b/p、d/t、g/k、n/l、f/h、平翘舌、前后鼻音、字形、声调、轻声、标调、ü、两拼三拼、整体认读、隔音符号、多音字等。
- 23 声母、24 韵母、16 整体认读音节，另有声调和规则卡，共 78 张知识卡；26 个字母大小写表。
- 人教统编语文现行修订版二年级上、下册：16 单元、55 教材课目；全量核对的 476 个教材词表词，以及 125 个明确标记的自编补充词，共 601 词条。每单元另有园地补充复习，独立于教材课目统计。
- 听音选择、拼音键盘自动检查、屏幕手写、纸上听写；按课听写、单元抽练、整单元听写。
- 跟读录音回听、本机保存进度、暂停续练、错题复习、记录备份导入导出。
- 789 段普通话合成音频，音频文件约 3.8 MB。

## 使用方式与边界

先听再作答，写好才揭晓。手写区支持手指和 Apple Pencil 笔迹输入，**不做手写识别**，需孩子或家长对照自评。录音仅在本页内存保存，关闭或切到后台即停止，不上传，也不做自动发音评分。录音不是听音练习的必要权限。

朗读是合成普通话，不是教师真人录音。拼音图谱播放完整例字音，帮助辨音，不冒充独立声母/韵母的专业示范录音。每次出题的汉字不在作答前显示；同音汉字词增加口头语境提示。

错题先隔 1 天复习；第一次答对后隔 3 天，第二次答对后隔 7 天，第三次到期复习答对记为“已巩固”。提前练习和看过答案立即改正，不累积间隔复习次数。出错重新开始这一轮。

记录只存在当前设备、当前浏览器。清理网站数据会清除记录；请在换设备或清理前到家长设置导出备份。没有跨设备自动同步、儿童账号、广告、排名或付费项目。

## 教材依据

采用核验当日（2026-11-06）国家中小学智慧教育平台提供的“根据 2022 年版课程标准修订”六三学制统编版。上册官方资源更新于 2026-08-18，下册于 2026-03-03；资源更新时间不等于首次出版版次。

完整来源与页码见 CURRICULUM-SOURCES.md；拼音口径见 PINYIN-SOURCES.md。学校实际听写范围以老师安排为准。

## 下载包怎么用

下载包包含完整应用文件、声音和维护源码，适合留存或迁移到自己的 HTTPS 网站。日常使用请打开正式网址；下载包需通过本机预览服务或 HTTPS 网站运行。

在电脑上预览（需要 Node.js 22.16+）：解压后运行 `npm start`，打开 `http://localhost:4173`。无需安装任何运行依赖。测试命令 `npm test`。部署前执行 `npm run build:release`，它根据主程序与题库内容生成缓存版本，确保后续修正可以更新。

验证信息见 VERIFICATION.md。没有连接实体 iPad；Apple Pencil 压感和防误触仍需在实际设备上确认。

## GitHub Actions 自动发布

推送私有源码仓库 main 后，CI 自动运行测试、生成缓存版本，再将 dist/ 发布至公开发布仓库的 gh-pages 分支，GitHub Pages 自动更新网站。配置与密钥范围见 DEPLOYMENT.md；后续 Agent 开发遵循 AGENTS.md，完成任务后验证、提交并推送。

## iPad 与响应式布局

首页直接提供今日练习、课文听写与错题入口。iPad 竖屏采用底部导航，宽屏练习采用听音与答题分栏；书写区随可用空间调整，旋转与暂停保留笔迹。弹窗支持正文滚动并适应可见窗口高度。手机使用单列，PC支持鼠标和键盘。

浏览器布局验证脚本为 `tests/ipad.browser.mjs`：先运行 `npm start`，再在具有 Playwright 的开发环境运行 `node tests/ipad.browser.mjs`。可通过 `PLAYWRIGHT_MODULE` 指定现有 Playwright 模块路径、`BROWSER_EXECUTABLE` 指定浏览器、`TEST_URL` 指定验证地址、`TEST_BROWSER=webkit` 切换到已安装的 WebKit；测试工具不进入网站产物。模拟验证不代表实体 iPad、Apple Pencil 或系统键盘真机验收。
