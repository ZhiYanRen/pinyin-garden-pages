# 拼音小花园 Implementation Plan
> For agentic workers: implement inline with superpowers:executing-plans; bounded content research delegated via Sites workflow.
**Goal:** Deliver installable iPad PWA with complete foundation topics and revised G2 lesson dictation.
**Architecture:** Buildless ES modules, local persistence, generated Mandarin audio, service worker, private Sites hosting.
**Tech Stack:** HTML/CSS/JS, Node test runner, Playwright Chromium + WebKit if available.
**Spec:** PRODUCT.md
## Global Constraints
Chinese UI; 48px targets; no child identifiers; no automatic handwriting/pronunciation grading claim; revised textbooks explicitly sourced.
## Review Focus
- Corrected mistakes must not immediately become mastered.
- Tones/ü/space normalization must not forgive wrong sounds.
- Audio blocked/record permission/offline failures remain recoverable.
- Refresh and repeated clicks must not duplicate grades or lose current exercise.
- Curriculum provenance and all lesson coverage must be honest.
## Tasks
1. [ ] Core: tests for pinyin comparison, schedules, import bounds, session grading; then implement core.js, storage.js.
2. [ ] App: implement shared layout and daily/pinyin/chart/textbook/review workflows, input/handwriting/recording; verify browser success and recovery.
3. [ ] Audio + installation: generate clip assets and manifest; cache only local static files; validate offline and export.
4. [ ] Integration: verify all lesson and topic data; review; fix; package + private deploy and instructions.
